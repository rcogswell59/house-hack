## Instructor guidance on product definition
Answer: What problem does it solve? Who is it for? How is it unique? Features must align with those answers. Then write user requirements (what the user experiences) and system requirements (operations and constraints, e.g. "NoSQL database stores user info"). Then user stories.

## Assignment 1 — Whiteboard architecture
- One paragraph answering the three questions above.
- High-level component diagram covering front-end and back-end, showing how components interact (e.g. front end ↔ back end via REST; separate processes for collection and analysis).
- "A perfect submission leaves no gaps in understanding the high-level architecture."
- Deliverable lives in `docs/assignments/01-whiteboard/`.
